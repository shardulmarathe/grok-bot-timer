# Contributing

Thanks for helping with Grok Bot Timer.

## Flow

1. Fork [shardulmarathe/grok-bot-timer](https://github.com/shardulmarathe/grok-bot-timer).
2. Create a branch from `main`.
3. Make the change.
4. Run `npm run build` and confirm it passes before you open a pull request.
5. Open a pull request against `main` and describe what changed.

`npm test` covers duration parsing. Browser checks in `tests/` need a local dev server and a Chrome or Chromium binary in `CHROME`.

## Design rules

Keep these intact unless the pull request is explicitly about changing them:

- Eyes are white slanted pills only. No pupils, and no black eyes.
- The hero's eyes always glide and never snap.
- Digits stay in fixed slots.
- Sound stays off by default.

The same rules are in the README.
